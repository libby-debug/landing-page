# ABA Mastered Curriculum Source of Truth

The canonical curriculum template for ABA Mastered is the official BACB BCBA Test Content Outline, 6th Edition PDF stored in the project root:

`BCBA-6th-Edition-Test-Content-Outline-240903-a.pdf`

Use this PDF as the permanent master reference for:

- Module structure
- Lesson mapping
- Practice test coverage
- Mastery check coverage
- ABA terminology
- Checklist organization
- Domain alignment
- Content expansion priorities

## Official Module Structure

- A. Behaviorism and Philosophical Foundations
- B. Concepts and Principles
- C. Measurement, Data Display, and Interpretation
- D. Experimental Design
- E. Ethical and Professional Issues
- F. Behavior Assessment
- G. Behavior-Change Procedures
- H. Selecting and Implementing Interventions
- I. Personnel Supervision and Management

## Development Rule

Before building, revising, or expanding any module, verify alignment against `BCBA-6th-Edition-Test-Content-Outline-240903-a.pdf`.

Every mini lesson, practice question, mastery question, checklist item, graph interpretation activity, and remediation item should map clearly to one or more official TCO 6 tasks. Preserve official BACB domain names, task numbering, and terminology where appropriate.

## Instructional Standards

Continue preserving the ABA Mastered learning style:

- Visual micro-learning
- BCBA-style conceptual discrimination
- Italicized full differentiating phrases
- Scenario-heavy practice
- Graph interpretation where appropriate
- Learn -> Practice -> Mastery progression
- 100% mini lesson advancement
- 90% mastery threshold
- Purple -> blue -> teal branding
- Glassmorphism styling
- Black graph lines with differentiated black markers
- Generic graph labels in tests
- Accessible, responsive layouts
